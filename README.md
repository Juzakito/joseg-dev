# Jose G. — Portfolio (Frutiger Aero / Windows Vista Style)

Portafolio interactivo estilo escritorio retro Windows Vista (Frutiger Aero) en HTML, CSS y Vanilla JS puro, sin dependencias.

## Estructura
- `index.html`: Todo el portafolio (estilos, iconos vectoriales SVG, animaciones Aero Glass y lógica de ventanas).

## Despliegue en Vercel
1. Este repositorio se despliega de forma estática directamente en [Vercel](https://vercel.com).
2. Sin comandos de build requeridos (`Build Command: None`, `Output Directory: ./`).
3. Conecta el dominio personalizado `joseG.dev`.
